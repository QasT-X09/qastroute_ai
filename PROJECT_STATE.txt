1. ТЕКУЩЕЕ СОСТОЯНИЕ ПРОЕКТА (ЧТО УЖЕ СДЕЛАНО И ЗАФИКСИРОВАНО)
--------------------------------------------------------------------------------
[x] Архитектура адаптеров (app/adapters/):
    - Базовый контракт ProviderAdapter с async интерфейсом и ProviderResponse.
    - Асинхронные неблокирующие клиенты для OpenAI, Anthropic, DeepSeek, Groq, Kimi, Mistral.
    - Локальный бесплатный мост FCC (Free Claude Code) на порту 8082.
    - Zero-Fabrication: исключены любые синтетические/фейковые ответы при сбоях (возврат строгого HTTP 502/504).

[x] Безопасность и аутентификация (app/security.py & app/billing.py):
    - Хеширование API-ключей по стандарту SHA-256 (в базе хранятся только key_hash и префикс).
    - Защита от утечек в логах (CWE-200): передача ключей через URL (?key=...) блокируется.
    - Защита от спуфинга IP (CWE-359): парсинг цепочки X-Forwarded-For справа налево с отсечением TRUSTED_PROXIES.
    - Защита от DoS больших тел (CWE-770): потоковый лимит 5 МБ для chunked и multipart запросов.
    - Bounded LRU Rate Limiting на 10,000 IP с автоматическим вытеснением старых адресов.
    - Строгие OWASP security headers (CSP, HSTS, X-Content-Type-Options, X-Frame-Options).
    - Идемпотентность вебхуков оплаты LemonSqueezy/Paddle (защита от Replay Attacks).

[x] Умный роутер и учет затрат (app/router.py & app/failover.py):
    - Режим model="auto" с анализом сложности промпта, объема контекста и наличия tools.
    - Автоматическая эскалация запросов с function/tool calling на флагманский уровень (Claude Fable / Opus).
    - Раздельный учет стоимости входных (input_cost_per_m) и выходных (output_cost_per_m) токенов.
    - Потокобезопасный BudgetGuard с суточными лимитами в SQLite и мягким дауншифтом на бесплатные модели при превышении квоты.

[x] Изолированный кэш (app/cache.py):
    - Полная изоляция по тенантам (tenant_id) — нулевой риск утечки данных между клиентами.
    - Хеширование параметров генерации (температура, системный промпт, tools, response_format).
    - Попадания в кэш (Cache Hits) учитываются с нулевой стоимостью ($0.00 spend).

[x] Дуальный стриминг (app/streaming.py):
    - Честный сквозной SSE-стриминг для протокола OpenAI (/v1/chat/completions).
    - Честный сквозной SSE-стриминг для протокола Anthropic (/v1/messages).

[x] Развертывание и контейнеризация:
    - Dockerfile с непривилегированным пользователем (qastuser, UID 10001).
    - docker-compose.yml с healthcheck-пробами и монтированием тома data/.
